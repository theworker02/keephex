# keephex

Keep structured JSON hex payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/keephex/

## Install / run

```bash
git clone https://github.com/theworker02/keephex.git
cd keephex
node src/cli.js
node --test
```
